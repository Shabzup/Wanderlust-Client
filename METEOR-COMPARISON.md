# Meteor module comparison

Source: [Meteor's registered modules](https://github.com/MeteorDevelopment/meteor-client/blob/master/src/main/java/meteordevelopment/meteorclient/systems/modules/Modules.java), reviewed 9 November 2026. Its registry has 169 modules. Wanderlust's 225 menu entries also include modules from the extra screenshot columns. Names in this table identify corresponding features, not equal behavior. See [MODULE-AUDIT.md](MODULE-AUDIT.md) for Wanderlust behavior evidence. Work through each row by reviewing Meteor's settings and behavior, implementing independent code, then recording a specific gameplay scenario.

### Current implementation pass

**AutoReplenish:** Meteor's [source](https://github.com/MeteorDevelopment/meteor-client/blob/master/src/main/java/meteordevelopment/meteorclient/systems/modules/player/AutoReplenish.java) exposes minimum count, delay, offhand, unstackable, enchant matching, hotbar search and excluded items. Wanderlust now exposes corresponding controls. Its new engine merges low stacks, restores emptied slots, refills offhand and replaces used unstackable items using normal inventory clicks. The integrated-world probe passed low-stack, offhand, empty-slot and disable checks. Tool matching, exclusions and multiplayer server behavior still need dedicated scenarios. The implementation is independently written; matching names and settings do not imply all edge cases match Meteor.
